# AI 小講義

給 AI 新手的簡短講義網站（純 HTML/CSS，無需建置）。

- 網頁：`https://<你的帳號>.github.io/<repo 名稱>/`
- AI 開發規則：請見 [CLAUDE.md](CLAUDE.md)

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 部署到 GitHub Pages

1. 將專案推送到 GitHub 的 `main` 分支。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
3. 等待約 1 分鐘，即可從網址瀏覽。

## 新增講義

對 AI 說：「依照 CLAUDE.md，新增一份關於 XXX 的講義」。
